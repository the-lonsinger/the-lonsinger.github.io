Servitor: Privacy Policy

Servitor is a personal desktop assistant used only by its developer, Matthew Lonsinger, on his own computer. It is not offered to the public.

What it accesses. With the owner's consent, Servitor uses the Gmail API (gmail.modify scope) to read message headers, snippets and, when needed, short excerpts of messages in the owner's own inbox, in order to apply labels, archive messages, and create draft replies. It never sends, deletes, or trashes mail.

Where data goes. Mail data stays on the owner's computer. Short, redacted excerpts may be sent to Anthropic's Claude API for classification. No data is sold, shared with third parties for advertising, or used for any purpose other than organizing the owner's inbox.

Storage. The OAuth token and a local activity log are stored only on the owner's computer. Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
